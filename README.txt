DESPLIEGUE EN GITHUB PAGES

1. Descomprima el paquete.
2. Suba index.html, datos_presupuesto_participacion_2026.json y .nojekyll a la raíz del repositorio.
3. En GitHub abra Settings > Pages.
4. Seleccione Deploy from a branch.
5. Elija la rama y la carpeta /(root).
6. Use la URL publicada como evidencia del punto:
   6.2.2.a. Porcentaje del presupuesto para el proceso.

OBSERVACIÓN TÉCNICA

El dashboard usa únicamente el rubro directamente identificado como
“Servicio de promoción a la participación ciudadana”.

No suma otros programas relacionados con convivencia, asistencia técnica,
control social o atención comunitaria para evitar sobreestimar el porcentaje.

El indicador representa apropiación presupuestal para promoción de la
participación ciudadana. No afirma, por sí solo, que ese monto haya sido
asignado mediante acuerdos de presupuesto participativo con la comunidad.
